## Zeta 0.6.2

- Desktop Zeta installs and updates a verified copy of yt-dlp from its official GitHub releases.
- YouTube playback and downloads retry the older yt-dlp player-script failure with the same selected cookies.
- Zeta Discord adds listening commands, Wayship playback control, voice sharing, and a Discord Activity with cover art and synced lyrics.

The fork's Android APK uses a separate signing key. Back up your library before replacing an upstream Android installation.
