## Zeta 0.6.4

- Desktop and Android builds check for updates from [gammadevv/z3](https://github.com/gammadevv/z3/releases).
- This release includes the Wayship reconnection fixes, managed yt-dlp updates, and the Zeta Discord bot’s playback and listening commands.
- GitHub Actions publishes the release after verifying the Windows, macOS, Linux, and signed Android packages.

Install a package from this release to switch to the fork’s update feed. The Android APK uses the fork’s signing key. Back up your Zeta library before replacing an upstream Android install.
